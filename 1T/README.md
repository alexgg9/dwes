# Manual de Desarrollo Web en Entorno Servidor (DWES)
## Alejandro Gálvez García

Este repositorio contiene los apuntes, manuales y ejemplos prácticos de código desarrollados durante la asignatura de **Desarrollo Web en Entorno Servidor (DWES)**. Los apuntes se organizan por semanas, y cada archivo incluye ejemplos prácticos de los conceptos aprendidos en clase.

## Contenidos

### Semana 1: Introducción a PHP

En la primera semana hemos trabajado con los fundamentos de **PHP**. A continuación se resumen los temas abordados:

- **Sintaxis básica de PHP**: cómo utilizar `echo`, `print` y `printf` para imprimir en pantalla.
- **Concatenación de cadenas**: combinar varias cadenas en una sola.
- **Manejo de variables**: declaración de variables y sus tipos de datos, como `string`, `int`, `boolean`, `array`, entre otros.
- **Estructuras de control**: uso de condicionales (`if`, `else`) y bucles (`foreach`).
- **Ámbito de variables**: diferencia entre variables locales y globales, y el uso de variables estáticas dentro de funciones.
- **Funciones útiles**: uso de `gettype()`, `var_dump()`, `isset()`, y `unset()` para trabajar con variables.
- **Manejo de fechas**: ejemplos con la función `date()` para formatear fechas en diferentes formatos.
- **Variables especiales**: explicación y uso de superglobales como `$_POST`, `$_GET`, `$_SERVER`, `$_SESSION`, `$_COOKIE`, entre otras.
