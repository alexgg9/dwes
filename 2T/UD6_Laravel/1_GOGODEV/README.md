
# Documentación Laravel Curos GOGODEV

###Realizado por Alejandro Gálvez

## 1. Fundamentos
Este módulo cubre los conceptos básicos de Laravel, incluyendo:
- Instalación y configuración de Laravel
- Estructura de directorios
- Configuración de variables de entorno
- Uso de Artisan para comandos básicos

## 2. Blade
Blade es el motor de plantillas de Laravel. Aquí se revisan:
- Sintaxis básica de Blade
- Uso de directivas (@if, @foreach, @include, etc.)
- Layouts y secciones para organizar las vistas

## 3. Migraciones y Modelos
En este módulo se trabaja con la base de datos mediante Eloquent y migraciones:
- Creación y ejecución de migraciones
- Definición de modelos y sus relaciones
- Uso de factories y seeders para poblar la base de datos

## 4. Controladores
Los controladores manejan la lógica de la aplicación. Se revisa:
- Creación de controladores con Artisan
- Métodos de controladores y rutas
- Uso de Request y Response

## 5. CRUD (Create, Read, Update, Delete)
Aquí se implementan las operaciones básicas sobre la base de datos:
- Creación de registros con formularios y validaciones
- Lectura de registros con paginación
- Edición y eliminación de registros

## 6. API
Se trabaja con la creación de APIs utilizando Laravel:
- Creación de rutas API
- Controladores de tipo API
- Uso de Postman para pruebas

## 7. Factory
Se utilizan factories para la generación de datos de prueba:
- Creación de factories con Artisan
- Uso de Faker para generar datos
- Inserción de datos con seeders

## 8. Relaciones
Eloquent permite definir relaciones entre modelos:
- Relaciones uno a uno, uno a muchos y muchos a muchos
- Uso de métodos en modelos para definir relaciones
- Carga de relaciones con `with()`

## 9. Middleware y Autenticación
Se revisa la autenticación en Laravel:
- Creación de middleware para seguridad
- Uso de Laravel Breeze para autenticación
- Protección de rutas con middleware

## 10. Breeze y Auth
Se profundiza en la autenticación utilizando Laravel Breeze:
- Instalación y configuración de Breeze
- Registro, inicio de sesión y cierre de sesión
- Protección de rutas y acceso restringido

## 11. Testing
Se exploran pruebas automatizadas en Laravel:
- Uso de PHPUnit para pruebas unitarias
- Pruebas de integración con Laravel
- Simulación de peticiones HTTP en pruebas
